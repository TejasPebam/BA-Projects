# AdventureWorks Sales Dashboard

A Power BI dashboard built using AdventureWorks sales data to analyze business performance.

## Features
- Total Sales, Orders, and Customers
- Sales by Category and Region
- Sales Trends over Time
- Interactive Date Slicer

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- MySQL
- CSV Files
